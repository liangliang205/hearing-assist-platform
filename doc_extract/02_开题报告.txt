| 1. 本课题研究意义及国内外发展状况 / 1.1 研究意义 / 听力损失及相关功能受损会影响个体的信息获取、交流和社会参与。近年来，青少年和年轻成年人在长时间耳机使用、娱乐场所高声环境等场景下面临的噪声暴露风险受到持续关注，相关研究表明，娱乐性噪声暴露与年轻人听力功能变化之间存在值得重视的关联[1-2]。因此，面向年轻听障人群提供更加便捷、可个性化配置的数字化辅助工具具有现实需求。 / 现有数字视频无障碍研究表明，字幕能够帮助听障用户获取语音信息，但对于音乐、环境声、非语音提示等听觉信息，仅提供语音文字转写仍存在不足；同时，不同听障用户对字幕内容呈现方式和声音提示的需求存在差异[10-13]。另一方面，助听设备和相关研究中的频率压缩、频率搬移等频率降低技术，可以改变部分频段信息的呈现位置，为改善特定频率信息的可听性提供了技术思路[7-9]。 / 基于上述背景，本课题拟设计并实现一个基于 React+TypeScript、NextJS 和 FastAPI AI 微服务的听障辅助视频处理及听力自测平台，集成 AI 字幕生成、个性化听力自测和频谱重映射等功能。课题在软件工程层面重点探索语音识别、Web 音频处理与业务系统的模块化集成，模块设计参考移动听力测试与智能手机听力筛查研究中对测试流程、家庭环境及测试可靠性的讨论，将听力自测定位为辅助筛查和个性化参数采集，而非医疗诊断[3-5]。 / 本课题的研究意义主要体现在：一是通过 AI 字幕与视频辅助处理降低听障用户获取视听信息的门槛；二是通过听力自测形成个体化听力特征，为音频增强参数提供依据；三是探索 Web 端频谱处理与 AI 微服务结合的工程实现方式；四是通过模块化、可部署的 Web 平台，将字幕辅助、听力自测和音频增强形成较完整的功能闭环。 / 1.2 国内外发展状况 / 国外相关研究主要集中在语音识别、听力筛查、助听信号处理和数字无障碍等方向。在语音识别与自动转写方面，已有研究将 Whisper 与 WhisperX 应用于自动语音转写、时间戳对齐和说话人分离，并可进一步生成 SRT 等字幕文件，为视频字幕自动生成提供了工程参考，并逐步与语音活动检测、说话人分离及时间信息处理结合，为视频字幕自动生成提供了工程参考[14]。在听力自测方面，智能手机和移动终端听力测试已形成较系统的研究，相关研究从系统综述、多中心验证到真实家庭环境测试，均表明移动听力测试具有较好的应用潜力，但测试设备、环境噪声与校准条件会影响结果，需要在平台设计中充分考虑[3-5]。 / 在听力辅助方面，研究者持续关注频率压缩、频率成分调整以及个体之间对信号处理策略的差异，相关研究提示：不同用户对信号处理变化的收益并不一致，因此个性化参数配置具有研究价值[7-9]。在无障碍方面，针对听障和重听人群的字幕研究进一步关注字幕的可用性、非语音信息呈现以及声音与音乐提示等问题，说明“字幕内容是否完整、是否符合用户偏好”同样是辅助系统设计的重要因素[10-13]。 / 国内相关研究也逐渐从传统听力筛查扩展到数字化听力测试和无障碍信息获取。已有研究对数字语音测试在听力筛查中的应用进行了探索；针对中国听障用户的字幕可获得性与接受度，也出现了较新的实证研究[6,10]。总体来看，现有研究往往聚焦于字幕、听力测试或音频处理中的单一环节，而将 AI 字幕、个性化听力自测和频谱重映射整合为统一 Web 平台的研究与工程实现仍有进一步探索空间。 / 因此，本课题以软件工程实现为主线，尝试将相关研究成果转化为可操作的 Web 功能模块，在保证系统可实现性的同时，突出听障用户的个性化辅助需求，并通过模块化架构提高后续扩展与部署能力。 | 1. 本课题研究意义及国内外发展状况 / 1.1 研究意义 /
